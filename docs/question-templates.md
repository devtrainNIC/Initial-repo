# Question Templates for Parking Lot

Copy and paste these templates into [Issue #11](https://github.com/devtrainNIC/Initial-repo/issues/11) when asking questions.

## 🔄 Git Workflow Question

```markdown
## Git Workflow Question

**What I'm trying to do:**
[e.g., "Create a new branch and switch to it"]

**Command I used:**
```bash
[paste the command here]
```

**What happened:**
[describe the result or error]

**What I expected:**
[what you thought would happen]
```

## 🐙 GitHub Features Question

```markdown
## GitHub Features Question

**Feature I'm asking about:**
[e.g., "Pull Requests", "Issues", "Branching"]

**Question:**
[your specific question]

**Context:**
[what you were trying to accomplish]
```

## Activity Help

## 🛠️ Technical Issue

```markdown
## Technical Issue

**Problem:**
[brief description]

**Error message:**
```
[paste exact error message here]
```

**System info:**
- Operating System: [Windows/Mac/Linux]
- Browser: [if relevant]
- Git version: [if known]

**Steps to reproduce:**
1. [first step]
2. [second step]
3. [when error occurs]
```
