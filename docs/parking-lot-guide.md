# Parking Lot - Questions & Support Guide

Welcome to our training Parking Lot! 🅿️ This is your go-to place for asking questions during the GitHub for Developers training.

## How to Use the Parking Lot

The Parking Lot ([Issue #11](https://github.com/devtrainNIC/Initial-repo/issues/11)) is designed to collect questions that come up during training. Here's how to make the most of it:

### 📝 How to Ask a Question

1. **Go to [Issue #11](https://github.com/devtrainNIC/Initial-repo/issues/11)**
2. **Click "Add a comment"**
3. **Use the templates below** to structure your question
4. **Add relevant labels** if you have permission (e.g., `question`, `help wanted`)

Use these categories to help organize your questions:

#### 🔄 **Git Workflow Questions**
Questions about Git commands, branching, merging, and workflow.

#### 🐙 **GitHub Features**
Questions about GitHub-specific features like Pull Requests, Issues, Projects, etc.

#### 🚀 **Activity Help**
Need help with specific training activities or exercises.

#### 🛠️ **Technical Issues**
Problems with setup, tools, or technical difficulties.

#### 💡 **Best Practices**
Questions about recommended approaches and best practices.

## 🎯 Tips for Great Questions

### ✅ Do
- **Be specific** - Include exact error messages, commands you ran, etc.
- **Provide context** - What were you trying to accomplish?
- **Show what you've tried** - This helps avoid duplicate suggestions
- **Use code blocks** for commands and error messages
- **Include screenshots** when helpful (drag and drop images into comments)

### ❌ Avoid
- Vague questions like "Git isn't working"
- Asking multiple unrelated questions in one comment
- Not providing enough context for others to help

### Common Issues & Solutions

#### "I can't push my changes"
- Check if you have the right permissions
- Make sure you're on the correct branch
- Try `git status` to see your current state

#### "I have a merge conflict"
- Don't panic! This is normal
- Review [Day 2 materials](./day2.md) for merge conflict resolution
- Ask for help with the specific conflict you're seeing

#### "I don't see my changes in the pull request"
- Make sure you've committed your changes (`git commit`)
- Push your branch to GitHub (`git push origin branch-name`)
- Check that you're looking at the right pull request
